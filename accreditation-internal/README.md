# 기관평가인증 편람 — 내부용(담당자 전용)

주소(올린 뒤): https://nightbird91.github.io/CCU-Jung/accreditation-internal/

## 보급용과 나누는 방식

| 구분 | 위치 | 고치면 |
|---|---|---|
| 화면·기본 기능 | `accreditation/assets/app.js`, `style.css`, `acc.css` | 보급용·내부용 함께 바뀜 |
| 편람 데이터·문서 | `accreditation/data/`, `accreditation/docs/` | 보급용·내부용 함께 바뀜 |
| 참고자료(암호화) | `accreditation/data/refs.json`, `accreditation/refs/` | 같은 자료·같은 비밀번호 |
| 내부용 기능 | `accreditation-internal/assets/internal.js`, `internal.css` | 내부용만 바뀜 |
| 담당자 명단(암호화) | `accreditation-internal/data/staff.enc.json` | 내부용만 |
| 내부용 첫 화면 | `accreditation-internal/index.html` | **직접 고치지 않음** (아래 생성) |

- 내부용 `index.html` 은 보급용 `index.html` 에서 자동으로 만듭니다: `python3 site-tools/build_internal.py`
  보급용 `index.html` 을 고친 뒤에는 이 명령을 한 번 돌려 함께 올립니다.
- `app.js` 에는 내부용을 위한 연결점(`window.ACC_EXT`, `window.ACC_ROOT`)만 있고, 보급용에서는 아무 일도 하지 않습니다.
- 미리보기(Claude 아티팩트): `python3 site-tools/build_internal.py --artifact` → `/mnt/project-files/artifact/accreditation-internal.html`

## 담당자 전용 사용 흐름

1. 설정 → 보기 방식 **담당자 전용** → **내 전화번호 뒤 4자리** 입력
2. 바로 내 평가영역 → 평가준거 → 평가요소만 표시(이름 목록은 보이지 않음). ‘전체 보기’로 편람 전체 열람
3. 평가요소 화면: 내 요소에만 주·부 담당자와 **내 준비 체크리스트**(준비 전/작성 중/완료, 평가활용 참고자료 체크, 메모)
4. 첫 화면 진행 막대, **내 평가요소 엑셀** 받기
5. 같은 4자리를 쓰는 담당자가 둘 이상이면 들어갈 때 이름을 고름
6. 관리자: 설정 → 담당자 명단 관리에 **담당자 지정 관리자 비밀번호** 입력 → 목차의 **담당자 현황**(영역별 표·담당자별 건수·미지정 요소, 엑셀). 이 블록은 담당자 전용 모드에서만 보임

※ 준비 상태·체크·메모는 각자 기기(브라우저)에만 저장됩니다.

## 관리자: 담당자 명단 올리기

0. 설정 → 담당자 명단 관리 → **담당자 지정 관리자 비밀번호** 입력. 이 비밀번호를 넣어야 양식 받기·엑셀 올리기가 보입니다.
   - 처음 비밀번호는 보급용 **참고자료 다운로드 비밀번호**와 같습니다(`accreditation/data/refs.json` 으로 확인).
   - 들어간 뒤 ‘담당자 지정 관리자 비밀번호 설정’에서 새 비밀번호(8자 이상)로 바꿀 수 있고, 바꾼 뒤에는 새 비밀번호만 통합니다.
1. **담당자 지정 양식 받기** (평가요소 90개가 채워진 엑셀)
2. 한 줄에 담당 한 건: **평가요소 번호 · 전화번호(뒤 4자리) · 이름**(필수), 부서·구분(주/부)(권장), 평가요소·영역·평가준거(참고용 자동 채움), 비고. 여러 명이 맡으면 줄을 더 넣음. 담당자 현황 엑셀도 같은 모양이라 고쳐서 다시 올릴 수 있음
3. 파일 선택 → 읽은 결과(담당자 수, 미지정 요소, 번호 없는 담당자, 같은 번호) 확인 → 필요하면 새 관리자 비밀번호 입력(비워 두면 지금 비밀번호 유지). 엑셀 없이 비밀번호만 바꿀 수도 있음
4. **GitHub 올리기**(관리자 설정에 토큰 필요) 또는 **파일로 받기** 후 `accreditation-internal/data/staff.enc.json` 으로 교체
5. 담당자에게는 따로 비밀번호를 알릴 필요 없음(각자 전화 뒤 4자리). 명단 파일이 바뀌면 기억된 기기도 다시 번호를 묻습니다.

- 파일 구조(v3): `people[]` 담당자마다 자기 4자리로 잠근 몫(내 평가요소와 함께 맡은 사람 이름·부서만, 전화번호 없음, 순서 섞음), `akdf`·`acheck` 관리자 비밀번호 확인값, `admin` 관리자 비밀번호로 잠근 전체 명단(전화 포함). `acheck` 가 없으면 참고자료 비밀번호로 확인. PBKDF2(SHA-256, 60만 회) → AES-GCM 256.
- 엑셀 원본과 평문 명단은 저장소에 올리지 않습니다.

## 현재 견본

- `data/staff.enc.json` 은 **가상 이름** 견본입니다(관리자 부분 없음 → 관리자는 참고자료 비밀번호로 들어감). Claude 미리보기에서는 참고자료 비밀번호를 `demo2028` 로 가정. 담당자 번호는 `review/가상담당자_전화뒤4자리.txt`(예: 한가람 2101).
- `review/담당자지정_견본(가상).xlsx` 는 업로드 시험용(저장소에 올리지 않음). 만드는 스크립트: `site-tools/make_internal_demo.py`
- 엑셀 읽기·쓰기는 `assets/vendor/xlsx.full.min.js`(SheetJS 0.18.5, Apache-2.0)를 필요할 때만 불러옵니다.

## 보안 수준

GitHub Pages 는 공개 사이트라서 이 페이지 주소와 암호화 파일은 누구나 받을 수 있습니다.
- 담당자 4자리는 경우의 수가 1만 개뿐이고 내선번호는 교내에 알려진 번호이므로, **'내 몫만 골라 보여 주는 문'** 정도로 봐야 합니다. 마음먹은 사람이 파일을 받아 번호를 모두 대입하면 각 담당자 몫(맡은 평가요소, 함께 맡은 사람 이름·부서)은 풀 수 있습니다. 반복 횟수를 크게 해 시간을 늦췄을 뿐입니다.
- 전체 명단과 전화번호는 관리자 비밀번호로 따로 잠겨 있어 이 방법으로는 풀리지 않습니다. 관리자 비밀번호는 길게 정하세요.
- 개인 계정 로그인이 필요해지면 교내 서버나 학교 구글 계정 기반 호스팅으로 옮겨야 합니다.
