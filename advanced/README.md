# 학사학위 전공심화 운영진단 편람 열람 웹페이지

전문대학 학사학위 전공심화과정 **3주기(2027~2029) 운영진단 편람**의 구분 → 분야 → 영역 → 진단지표를 휴대폰에서 열람하기 위한 정적 웹페이지입니다. 빌드 과정이 없어 GitHub Pages에 그대로 올리면 됩니다.

## 구성
```
index.html          화면 틀 (상단바, 하단 탭)
assets/style.css    모바일 우선 스타일 (다크모드 자동 대응)
assets/app.js       화면 렌더링·검색·점수 계산기
data/manual.json    편람 내용 (이 파일만 고치면 내용이 바뀝니다)
```

## 화면
- **지표체계** : 100점 배점 요약, 정량/정성/혼합 필터, 구분·분야·영역별 카드 또는 총괄표
- **지표 상세** : 개요(진단방향·용어) / 진단요소(증빙 번호) / 작성자료·지침 / 진단척도(+정량 지표 점수 계산기) / 3주기 변경
- **검색** : 지표명, 진단요소, 증빙자료, 작성지침, 산출식 전체 검색
- **기본계획** : 등급(S·A·B·C) 기준과 활용, 연차별 일정, 진단 대상, 정량요소 총괄표
- **변경사항** : 2주기 대비 3주기 변경 내용

## GitHub Pages 배포
1. 이 폴더의 파일을 저장소 루트(또는 `docs/`)에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)`(또는 `/docs`)로 지정합니다.
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 주소로 누구나 열람할 수 있습니다.

## 편람 내용 수정
`data/manual.json`의 각 지표(`indicators`)에서 `direction`(진단 방향), `elements`(진단요소), `evidence`(증빙자료), `forms`(작성자료), `scales`(진단척도), `changes`(변경사항)를 고치면 됩니다. 로컬에서 확인하려면 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000`을 엽니다(파일을 더블클릭해 열면 데이터가 로드되지 않습니다).

※ 본 페이지는 열람 편의를 위한 정리본이며, 정확한 내용은 편람 원문을 확인하세요.
