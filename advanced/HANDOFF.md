# 디자인·개발 명세서 (Handoff Spec)
## 전문대학 학사학위 전공심화 운영진단 편람 웹페이지

- 공개 주소: https://nightbird91.github.io/CCU-Jung/advanced/
- 제작: 충청대학교 교수학습지원실
- 최종 정비: 2026-11-21

---

### 1. 개요
학사학위 전공심화과정 운영진단 편람(3주기)을 휴대폰·PC에서 바로 찾아볼 수 있게 정리한 정적 웹페이지입니다. 사용자는 교직원과 학과 담당자입니다. 진단지표를 찾고, 산식·척도·작성자료를 원문 쪽 이미지로 확인하는 것이 주된 목적입니다.

- **기술 구성:** 빌드 과정이 없는 정적 SPA입니다(HTML + CSS + 순수 JavaScript). 파일을 그대로 올리면 동작합니다.
- **파일 구성:**

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대(상단 블록, 설정 창, 사이드바, 본문, 하단 탭, 문서 팝업) |
| `assets/style.css` | 스타일. 맨 위에 디자인 토큰이 있고, 10개 구역으로 나뉩니다. |
| `assets/app.js` | 라우팅, 화면 그리기, 팝업, 검색, 계산기 |
| `data/handbooks.json` | 편람 목록(연도별 기준 편람) |
| `data/manual.json` | 2027 편람 내용(지표·진단요소·증빙·작성자료·척도·산식·변경사항) |
| `docs/2027/` | 원문 쪽 이미지와 PDF(`pages/`, `forms/`, `changes/`, `summary.*`) |
| `assets/img/` | 로고(한국전문대학교육협의회 `kcce-logo.png`, 충청대 `ccu-symbol.png`(선택)) |

- **화면 주소(해시 라우팅):** `#/` 지표 체계, `#/c/<구분>`, `#/f/<분야>`, `#/i/<지표ID>`(예: `#/i/2.1.1.2`), `#/plan` 기본계획·등급 기준, `#/changes` 변경사항(3주기), `#/search` 검색.

### 2. 레이아웃과 화면 폭 기준점
기준점은 3단계로 통일했습니다. 새 규칙도 이 세 구간 안에서만 작성합니다.

| 구간 | 폭 | 화면 구성 |
|---|---|---|
| 휴대폰 | ~599px | 상단 블록(제목 두 줄) + 본문 + 하단 탭 4개. 목차는 왼쪽 서랍입니다. 팝업은 전체 화면이고, 글 팝업은 아래에서 올라옵니다. |
| 태블릿 | 600~999px | 제목이 한 줄로 바뀝니다. 본문 폭은 최대 860px이고 좌우 여백은 24px입니다. 목차 서랍과 하단 탭은 휴대폰과 같습니다. |
| PC | 1000px~ | 왼쪽 사이드바(288px)가 항상 보이고, 하단 탭과 목차 버튼은 숨깁니다. 본문은 최대 960px이며 가운데 정렬합니다. |

- 예외는 하나입니다. 진단지표 제목(`.detail-head h2`)은 720px부터 26px로 커집니다.
- 휴대폰 하단에는 탭바 높이(`--tabbar-h` 62px)와 아이폰 홈 표시줄(`safe-area`)만큼 여백을 둡니다.

### 3. 디자인 토큰 (`assets/style.css` 맨 위)

### 4. 주요 컴포넌트

| 컴포넌트 | 클래스 | 설명 |
|---|---|---|
| 상단 블록 | `.hero` | 회색 바탕에 위(빨강·주황)·아래(초록·파랑) 4px 띠를 두고, 가운데에 제목을 둡니다. 휴대폰·태블릿에서는 왼쪽 끝에 목차, 오른쪽 끝에 설정 아이콘(34px 원)이 있습니다. 휴대폰에서는 아이콘을 둘째 줄 높이(+14px)에 맞춥니다. PC는 오른쪽에 "설정" 글자 버튼만 둡니다. |
| 설정 창 | `.settings-panel` | 발행 기관 로고, 기준 편람 선택, 편람 정보(진단기준년도 등), 총괄표·변경사항 원문 버튼, 제작 기관을 담습니다. 창 바깥은 어둡게 처리합니다. |
| 목차 트리 | `.tree .t1~.t4` | 구분 › 분야 › 영역 › 진단지표 4단계입니다. 단계마다 접고 펼 수 있고, 상태는 `localStorage jsh-toc`에 저장합니다. 진단지표 줄은 테두리 있는 칸에 색 번호 배지를 붙이고, 선택하면 구분 색으로 채웁니다. |
| 지표 목록 | `.ind` | 지표 이름, 유형 칩, 점수 배지(`.ipts`, 폭 40px·글자 11px 고정, 지표마다 다른 색)를 보여 줍니다. |
| 구역 칩 | `.toc` | 개요·진단요소·작성자료·진단척도·3주기 변경으로 바로 이동합니다. 스크롤 위치에 따라 선택 표시(초록)가 바뀝니다. |
| 팝업 버튼 | `.form-btn` + `.lbl.표/기술/산식/척도/변경` | 누르면 원문 쪽 이미지 팝업(`openDoc`)이나 글·표 팝업(`openInfo`)이 열립니다. |

| 상태 화면 | `.state`, `.spinner`, `.retry-btn` | 불러오는 중이거나 오류일 때 보여 줍니다(6절). |

### 5. 동작 (상호작용)

| 요소 | 동작 |
|---|---|
| 목차 아이콘 / 왼쪽 가장자리 스와이프 | 휴대폰·태블릿에서 서랍을 엽니다. 화면 왼쪽 32px 안에서 오른쪽으로 60px 이상 밀면 열리고, 열린 서랍을 왼쪽으로 밀면 닫힙니다. 아이폰·안드로이드의 "뒤로 가기" 제스처와 겹칠 수 있으므로 아이콘을 기본으로, 스와이프를 보조로 둡니다. |
| 서랍 바깥(어두운 막), Esc | 서랍을 닫습니다. |
| 설정 아이콘 | 설정 창을 열고 닫습니다. 창 바깥을 누르거나 Esc를 누르면 닫힙니다. |
| 문서 팝업 확대·축소 | 두 손가락 벌리기·오므리기(100~400%), 이미지 두 번 탭(기본 ↔ 2배), 오른쪽 아래 −/+ 버튼, PC는 Ctrl+휠. 페이지 전체가 아니라 이미지 영역만 커지고, 손가락 가운데 지점을 기준으로 확대합니다. 휴대폰은 150%, PC는 100%로 열립니다. |
| 팝업 | Esc, 바깥 누르기, 닫기 버튼, 페이지 이동 시 닫힙니다. 닫으면 열었던 버튼으로 포커스가 돌아갑니다. 열려 있는 동안 Tab 키는 팝업 안에서만 돕니다. |
| 구역 칩 | 누르면 해당 구역으로 이동하고, 1.2초 동안 스크롤 감지를 멈춰 선택 표시가 흔들리지 않게 합니다. |
| 화면 바탕(설정) | 자동(기기 설정) · 흰 바탕 · 검은 바탕 중에서 고릅니다. `html[data-theme]`로 적용하고 `localStorage jsh-theme`에 저장합니다. 페이지를 열 때 `<head>`의 짧은 스크립트가 먼저 적용해 화면 깜빡임을 막습니다. |
| 기준 편람 선택 | 고르면 "불러오는 중" 화면을 보여 준 뒤 해당 편람으로 전체를 다시 그립니다. 선택은 `localStorage jsh-hb`에 저장합니다. |
| 움직임 | 서랍은 0.25초, 화살표 회전은 0.2초입니다. 기기에서 "동작 줄이기"를 켜면 전환 효과를 끕니다. |

### 6. 상태와 예외 상황

| 상황 | 화면 |
|---|---|

| 불러오기 실패 | "편람 데이터를 불러오지 못했습니다"와 원인, **다시 시도** 버튼을 보여 줍니다. 파일을 직접 연 경우에는 웹 주소로 접속하라고 안내합니다. |
| 느린 회선 | 20초 안에 응답이 없으면 "응답 시간 초과" 오류 화면으로 바꿉니다. |
| 결과 없음 | 검색 결과가 없거나, 지표를 찾을 수 없거나, 해당 유형 지표가 없으면 안내 문구를 보여 줍니다. |
| JavaScript 꺼짐 | 켜 달라는 안내를 보여 줍니다(`noscript`). |
| 긴 글자 | 줄바꿈은 단어 단위(`keep-all`)로 합니다. 표는 가로로 스크롤합니다. 사이드바 지표명은 여러 줄로 표시합니다. |
| 로고 없음 | `ccu-symbol.png`가 없으면 이미지를 숨기고 글자만 보여 줍니다. |

### 7. 접근성
- 모든 아이콘 버튼에 `aria-label`(목차 열기, 설정, 닫기)을 붙입니다. 팝업에는 `role="dialog"`, `aria-modal`, `aria-labelledby`를 둡니다.
- 키보드 포커스는 주황 2px 테두리(`--focus`)로 표시합니다. 마우스로 누를 때는 표시하지 않습니다(`:focus-visible`).
- 터치 범위는 최소 44px입니다. 상단 아이콘은 보이는 원이 34px이지만 투명한 확장 영역으로 44px을 확보합니다.
- 불러오기 상태는 `role="status"`, 오류는 `role="alert"`로 화면낭독기에 알립니다. 본문 영역은 `aria-live="polite"`입니다.

### 8. 새 편람(다음 연도) 추가 방법
1. `data/manual-<연도>.json`을 `manual.json`과 같은 구조로 만듭니다.
2. `docs/<연도>/`에 `summary.png/pdf`(총괄표), `pages/pNNN.png`(원문 쪽 이미지, 130dpi), `forms/*.pdf`, `changes/`를 넣습니다.
3. `data/handbooks.json`에 한 줄을 추가합니다: `id`, `name`, `evalYear`, `baseYear`(진단기준년도), `cycle`, `published`, `data`, `docs`, `changesPages`.
4. 설정의 "기준 편람"에 자동으로 나타납니다.

### 9. 수정·배포 절차
1. `/mnt/project-files/site/`를 수정합니다. 스타일은 해당 구역에 넣고 토큰을 씁니다. 맨 아래에 덧붙이는 방식(덮어쓰기 규칙)은 쓰지 않습니다.
2. `python3 /mnt/project-files/site-tools/build_artifact.py`로 미리보기용 단일 HTML을 만들어 Claude 미리보기에서 확인합니다.
3. 확정되면 저장소 `nightbird91/CCU-Jung`의 `advanced/` 폴더에 반영합니다. 루트 `index.html`(통합 웹서비스)은 건드리지 않습니다.
